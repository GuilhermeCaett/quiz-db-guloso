# Funil Quiz Diabético Guloso

Funil estático independente do webapp principal.

## Rodar localmente

```powershell
python -m http.server 4176
```

Abra `http://127.0.0.1:4176/funil-quiz-dbguloso/`.

## Integração

Edite o objeto `CONFIG` no início de `app.js`:

- `checkoutUrl`: URL de pagamento usada nos botões da oferta.
